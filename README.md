# 傅里叶本轮绘图

复刻「傅里叶本轮绘图法画甘肃地图」的轻量单页应用：对闭合轮廓的 X(t)、Y(t) 各做一套傅里叶级数，
用两组正交圆周链（各 K 个圆）合成笔尖，逐圈描出图形，实时显示级数展开式与相对 RMS 误差。

## 使用

双击打开 `index.html` 即可，无需构建、无外部依赖、可离线运行。

- **图形**：快捷片（甘肃 / 中国 / 蝴蝶曲线 / 心形 / 星形）+「更多图形」下拉（全部 34 个省级行政区、花 / 齿轮 / 三叶结等趣味曲线）
- **✎ 手绘**：在画布上画闭合轮廓，松手自动 Chaikin 平滑 + 弧长采样 + 级数展开；支持清除重画
- **🖼 图片轮廓**：上传 PNG/JPG，自动 Otsu 阈值分割（支持透明背景）→ 最大连通域 → Moore 边界追踪 → 简化成轮廓
- **谐波层数 K**：2 的幂（1→1024）；「自动加倍」开启时每描完一圈 K 翻倍，模拟收敛过程
- **公式面板**：实时笔尖坐标 + X(t)/Y(t) 级数前 4 项展开（`[+N 项]` 为剩余项数）
- **统计**：正在绘制 · 正交圆周 K × 2 组 · 相对 RMS 误差
- **🌙 深色模式**：右上角切换，跟随系统初始化，画布颜色随主题适配
- URL 参数：`index.html?shape=butterfly&k=8&auto=0&speed=0.4&theme=dark`

## 原理

1. 轮廓按**弧长均匀重采样** 2048 点（笔尖匀速，系数只依赖几何形状）
2. 基-2 FFT 分别求 X(t)、Y(t) 的实数傅里叶级数系数：
   `X(t)=a₀+Σ[Aₖcos(2πkt−δₖ)]`，`Y(t)=b₀+Σ[Bₖsin(2πkt+εₖ)]`
3. X 链（顶部）系数取复数 `Aₖe^{−iδₖ}` 旋转，链尖的横坐标恒等于 X(t)；
   Y 链（左侧）系数取 `Bₖe^{iεₖ}`，链尖纵坐标恒等于 Y(t)
4. 两链尖经虚线正交投影汇合成笔尖 → 描出 2D 图形；截断 K 项即为逆 DFT 重构
5. 笔尖高速段按微步插值记录笔迹，避免帧间直线切弯

## 文件

```
index.html              应用本体（HTML+CSS+JS 单文件逻辑）
shapes.js               内置轮廓数据：34 个省级行政区 + 中国（由脚本生成，184KB）
tools/build-shapes.mjs  轮廓数据构建：GeoJSON → DP 简化 → 归一化
tools/test-math.mjs     FFT/级数重构的数值自测
tools/test-trace.mjs    图片轮廓提取管线自测（连通域/边界追踪/简化）
.ref/                   参考视频与 GeoJSON 原始数据
```

轮廓数据来源：阿里云 DataV GeoAtlas。
